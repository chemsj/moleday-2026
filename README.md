# 내 숨은 몇 몰? — 가을 몰(Mole) DAY 2026

풍선 둘레를 누르면 **둘레 → 반지름 → 부피 → 몰수 → 분자 수 → 0.1 mol과 비교**를 그림과 식으로 차례로 보여 주는 부스용 화면입니다.

- 접속 주소: <https://chemsj.github.io/moleday-2026/>
- 스탠바이미를 세로(1080 × 1920)나 가로(1920 × 1080)로 두고 브라우저로 열면 됩니다. 오른쪽 위 전체 화면 버튼을 누르면 화면을 꽉 채웁니다.
- 아무도 만지지 않으면 「0.1 mol 풍선은 몇 cm?」(목표 둘레 구하기)가 되풀이되고, 3분 동안 손대지 않으면 처음 화면으로 돌아갑니다.

## 계산

| 단계 | 식 |
|---|---|
| 반지름 | r = C / 2π |
| 부피 | V = 4/3 × π × r³ (풍선을 공 모양으로 봄) |
| 몰수 | n = V / 24.5 L/mol (25 °C, 1 atm) |
| 분자 수 | N = n × 6.02 × 10²³ |

목표: 0.1 mol → 2.45 L → r ≈ 8.36 cm → **둘레 52.5 cm** (오른쪽 위 「0 °C」를 누르면 22.4 L/mol 기준, 둘레 51.0 cm)
